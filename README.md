# Учебная конфигурация 1С:Предприятие 8.3

> Конфигурация для автоматизации учёта закупок, продаж и складских операций

---

## 📋 О проекте

Учебная конфигурация, разработанная в рамках курса «Разработка конфигураций в системе 1С:Предприятие для сферы услуг». Проект демонстрирует навыки работы с основными объектами метаданных платформы 1С:Предприятие 8.3.

### Реализованные функции

- Ведение справочников: Номенклатура, Контрагенты, Валюты, Склады
- Документы: Поступление товаров, Реализация товаров
- Регистры сведений: Курсы валют, Артикулы товаров
- Отчёты на СКД: Прайс-лист, Ведомость закупок, Печать накладной
- Управляемые и обычные формы документов
- Ролевая модель и настройка прав доступа

---

## 🛠️ Использованные механизмы платформы

| Механизм | Что реализовано |
|----------|-----------------|
| **Справочники** | Номенклатура, Контрагенты, Валюты, Склады |
| **Документы** | Поступление товаров, Реализация товаров |
| **Регистры сведений** | Курсы валют (периодический), Артикулы (измерения: Номенклатура, Контрагент) |
| **СКД (Схема компоновки данных)** | Отчёты с группировками, отборами, условным оформлением |
| **Управляемые формы** | Формы документов с группировкой элементов, подвалом табличной части |
| **Константы** | УчетПоСкладам |
| **Функциональные опции** | Настройка видимости функционала |
| **Роли и пользователи** | ПолныеПрава, разграничение доступа |
